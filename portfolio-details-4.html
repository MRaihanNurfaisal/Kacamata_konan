Project Overview

This project is a web-based internal document management system developed using the CodeIgniter framework. It was designed for a corporate environment to handle the secure storage, approval, and numbering of official company letters. The system introduces a structured workflow that involves multi-level approval based on company hierarchy and ensures that each outgoing letter receives a unique, automatically generated document number.

Project Objective

  • Develop a centralized web-based platform to manage company letters and ensure organized digital storage with easy access.
  • Automate the letter numbering process to eliminate human error and prevent duplication of document numbers.
  • Provide an intuitive and user-friendly interface for both regular users and administrators to upload, view, approve, and manage letters efficiently.
  • Implement a structured multi-level approval system that reflects the hierarchy of company leadership and controls document flow accordingly.

My Role

  • Created interactive form inputs for uploading letters.
  • Integrated document preview components to allow users to view uploaded letters before submission.
  • Helped implement dynamic tables and modals for listing, viewing, and managing documents.
  • Worked closely with back-end to connect forms and tables to the database (CRUD integration) using CodeIgniter views.

Technologies Used

  • Database: MySQL
  • Tools & Utilities: Git, Composer, phpMyAdmin
  • Deployment: Local Server (XAMPP/LAMP)

Key Features

Letter Upload & Storage

Users can upload and manage company letters in a centralized digital system

Approval Workflow

Letters must be approved step-by-step by superiors in the hierarchy before progressing to the next stage

Automatic Letter Numbering

The core functionality generates unique letter numbers automatically to prevent duplication and maintain consistency in documentation

Letter Status Tracking

Admin and users can view the approval status of each letter in real time
