Project Overview

As an IT Support Engineer placed on Telkomsel's project at Neuronworks, I support data infrastructure operations at enterprise scale — covering application and server monitoring, database management, and cloud job orchestration. The role blends operational reliability with data engineering practices: keeping pipelines running, data accurate, and cloud environments in sync.

Project Objective

  • Ensure application, server, and database uptime through proactive monitoring and rapid incident response.
  • Maintain data accuracy and integrity across systems through structured reprocessing and anomaly handling.
  • Automate recurring data workflows to reduce manual intervention and human error.
  • Support a smooth, low-disruption migration of jobs, scripts, and schedules from AWS Cloud to Huawei Cloud.

My Role

  • Monitored applications, servers, and databases, responding to user tickets and chats within SLA.
  • Managed and queried multiple databases (PostgreSQL, Oracle, Redshift, ClickHouse) to fulfill data requests and support reporting needs.
  • Reprocessed anomalous or missing data to maintain data integrity across downstream systems.
  • Built and maintained automation scripts, configuring scheduled jobs using crontab.
  • Orchestrated and monitored data jobs on Apache Airflow, running them manually when not yet scheduled.
  • Performed database and server housekeeping, including approved data deletion, to keep storage capacity optimal.
  • Participated in migrating data pipelines, scripts, and schedules from AWS Cloud to Huawei Cloud.

Technologies Used

  • Database: PostgreSQL, Oracle, Redshift, ClickHouse
  • Orchestration & Automation: Apache Airflow, Crontab
  • Cloud Platforms: AWS, Huawei Cloud
  • Tools & Utilities: DBeaver, MobaXterm, GlobalProtect, Power BI
